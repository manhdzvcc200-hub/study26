# Study26 V6.2 FULL

- Passwordless live rooms: join code only.
- Teacher profile + avatar.
- Full class learning modules: assignments, submissions, grading, materials, schedules, attendance, analytics.
- Admin reads/manages system data through server APIs using SUPABASE_SERVICE_ROLE_KEY.
- No public AI page/API and no public purchase/upgrade page.

## Required environment

NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY (server only)
NEXT_PUBLIC_LIVEKIT_URL
LIVEKIT_API_KEY
LIVEKIT_API_SECRET

Run `supabase/study26_v6_2.sql` once. Then `npm install` and `npm run build`.
